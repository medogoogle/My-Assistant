# مساعدي — MyAssistant Android

تطبيق مساعد شخصي ومالي وتداول، يعمل بالكامل محليًا على جهازك (بدون إنترنت وبدون سيرفر خارجي).

## المزايا

- قائمة جانبية (Drawer) **قابلة للطي (أكورديون)**: "المال" و"التداول" لهما بنود فرعية (الحسابات / الحركات المالية / معاملات متكررة — سجل الصفقات / حاسبة المخاطرة) تفتح داخل نفس الشاشة وتنزلك مباشرة للقسم المطلوب، وباقي الأقسام تنتقل مباشرة. تمييز للقسم/البند الحالي، وعرض متجاوب مع حجم شاشة أي جهاز.
- **قفل بالبصمة** (اختياري، بجانب رمز PIN): من الإعدادات، إذا جهازك يدعم البصمة/الوجه، يظهر مفتاح "فتح التطبيق بالبصمة" — لما يكون مفعّل، شاشة القفل تفتح مستشعر البصمة تلقائيًا، ولسه فيه خيار الرجوع لرمز PIN كبديل دايمًا.
- **دعم أكثر من عملة**: كل حساب له عملته الخاصة (جنيه سوداني / دولار / يورو / ريال سعودي / درهم إماراتي / جنيه مصري / أخرى)، ولوحة اليوم تعرض إجمالي كل عملة منفصل بدل جمعها في رقم واحد غلط.
- **اختصارات الأيقونة**: اضغط مطولاً على أيقونة التطبيق (على أغلب الأجهزة) عشان تفتح مباشرة: صفقة جديدة / حركة مالية جديدة / دين جديد / مهمة جديدة، بدون ما تدخل الشاشة الرئيسية أولاً.
- لوحة رئيسية تعرض ملخص شامل + **تنبيهات** للديون القريبة من الاستحقاق والمهام غير المنجزة القريبة من موعدها.
- **تعديل وحذف وبحث** لكل سجل في كل شاشة (حسابات، حركات مالية، ديون، صفقات، استثمارات، مهام) — اضغط على أي عنصر لتعديله أو حذفه.
- حسابات مالية وحركات دخل/مصروف.
- ديون لك وعليك (مرتبة حسب أقرب تاريخ استحقاق)، مع تسجيل المدفوع.
- مهام مع إمكانية تحديد "تم الإنجاز".
- محفظة استثمار (ذهب فعلي / أسهم / عملات رقمية / عقار / أخرى) مع ربح وخسارة غير محقق.
- Trading Journal للذهب/XAUUSD (سكالب وصفقات قصيرة)، حاسبة الحد الأقصى للمخاطرة، ودعم أكثر من Broker (Exness وJustMarkets).
- **شاشة إحصائيات**: منحنى أداء التداول التراكمي، معدل الصفقات الرابحة، توزيع محفظة الاستثمار (رسم دائري)، الدخل والمصروف الشهري (رسم أعمدة) — كلها مرسومة داخليًا بدون أي مكتبة خارجية.
- **إعدادات**: تبديل بين الوضع الغامق والفاتح، اختيار لون رئيسي للتطبيق من 6 ألوان، كلها تُطبّق فورًا.
- **قفل بالرمز (PIN)**: تفعيل اختياري لرمز دخول عند فتح التطبيق، مخزّن بصيغة مُجزّأة (SHA-256) على الجهاز فقط.
- **نسخ احتياطي**: تصدير كل البيانات كملف JSON واحد لأي مكان تختاره (درايف، تخزين الجهاز...)، واستيرادها لاحقًا لاسترجاع كل شيء.
- **معاملات متكررة**: سجّل فاتورة أو إيجار شهري مرة واحدة، والتطبيق يضيفه تلقائيًا كل شهر عند فتحه.
- **تقرير شهري**: تصدير/مشاركة ملخص نصي (دخل ومصروف حسب التصنيف، ديون، تداول، استثمار) لأي شهر من آخر 3 أشهر.
- كل الحقول التصنيفية (نوع الحساب، دخل/مصروف، التصنيف، البروكر، الأولوية...) قوائم اختيار بدل الكتابة اليدوية، وحقول التاريخ تفتح تقويمًا بدل الكتابة اليدوية.
- حقول المبالغ لوحة مفاتيح رقمية وتتنسّق بفواصل الآلاف أثناء الكتابة تلقائيًا.
- الإنتر في لوحة المفاتيح ينقل للحقل التالي، ولمسة خارج أي حقل تُغلق الكيبورد مباشرة.
- قاعدة بيانات SQLite محلية بالكامل داخل الجهاز — لا شيء يُرسل لأي سيرفر.
- كل الأبعاد محسوبة بوحدة dp (مناسبة لأي حجم شاشة)، وزرار الرجوع في الجوال شغال بشكل طبيعي.

## MT5

تم تصميم قاعدة البيانات لتخزين broker/account/trade fields بحيث تكون جاهزة لطبقة MT5 Connector لاحقًا. MT5 نفسها ليس لديها API عام يسمح لتطبيق خارجي بالاتصال مباشرة بحساب بروكر عبر يوزر/باسورد، لذلك الربط التلقائي محتاج واحد من:
1. خدمة سحابية مدفوعة (مثل MetaApi.cloud) تتصل بباسورد Investor (قراءة فقط) وتشتغل مع أي بروكر بما فيه Exness وJustMarkets.
2. API الخاص بـ Exness نفسها (مجاني للحسابات العادية بعد توثيق الهوية) — يغطي Exness فقط.
3. سيرفر صغير (VPS) تشغّله بنفسك فيه MT5 + سكريبت يبعث بيانات الصفقات لتطبيقك.

هذا القرار لم يُحسم بعد، والتطبيق حاليًا يعمل بإدخال يدوي بالكامل، وقاعدة البيانات جاهزة لاستقبال المزامنة لاحقًا أيًا كانت الطريقة المُختارة.

## فتح المشروع

1. افتح المجلد في Android Studio.
2. دع Android Studio يعمل Gradle Sync.
3. استخدم JDK 17 أو النسخة التي يقترحها Android Studio.
4. Build > Build APK(s).

أو ارفع المشروع على GitHub ودع GitHub Actions يبني ملف الـ APK تلقائيًا (الطريقة الموصى بها إذا كنت لا تستخدم Android Studio).

لا يحتوي المشروع على بيانات دخول لأي Broker، ولا ينبغي وضع كلمات مرور التداول داخل التطبيق.
